# Phase 6 — รูปสินค้า Supplier · แจ้งเตือนกลุ่ม Lark อัตโนมัติ · ติดตามการขาย (New Item) · สรุป GP

เวอร์ชัน `2026.10.08-4`

## 1. รูปสินค้าจาก Supplier (สูงสุด 10 รูป / Supplier 1 เจ้า)
- หน้า **ใบเสนอราคา (SR)**: Supplier แต่ละเจ้า (แต่ละคอลัมน์) มีกล่อง **📷 รูปสินค้า n / 10** — กด ＋ เลือกได้หลายรูปพร้อมกัน, ✕ ลบรูปที่ตัวเองแนบ
  - แนบได้ทันทีแม้ยังไม่ได้กดบันทึกร่าง (รูปผูกกับ Supplier เจ้านั้นด้วย quote_id)
  - รูปจากมือถือ (4–12 MB) ถูกย่อเหลือ ≤ 1600 px (JPEG) ก่อนส่ง · HEIC ส่งตามเดิม
  - เลือกเกินที่เหลือ → แนบเฉพาะเท่าที่ยังว่าง พร้อมแจ้งเตือน · server ตรวจซ้ำ (ทั้งตอนเริ่มและตอนอัปโหลดเสร็จ) → `PHOTO_LIMIT`
  - ลบ Supplier เจ้านั้นออกแล้วบันทึก → รูปของเจ้านั้นถูกลบด้วย (แจ้งจำนวนรูปก่อนยืนยัน)
- หน้า **รายละเอียดใบ** (SR Manager / GM ตอนอนุมัติ): ใต้ตารางเทียบราคามี **📷 รูปสินค้าจาก Supplier** แยกตามเจ้า (ผู้ชนะขึ้นก่อน) · แตะรูป → ดูเต็มจอ เลื่อน ‹ › / ปัด / ปุ่มลูกศร · “เปิดไฟล์ต้นฉบับ”
- รูปแสดงผ่าน `getPhotoPreviews` (server อ่านภาพให้ ผู้ดูไม่ต้องมีสิทธิ์ Drive · thumbnail cache 6 ชม.)
- **Sales / Sales Manager ไม่ได้รับรูปเลย** (เป็นข้อมูลฝั่งซื้อ เหมือนไฟล์ใบเสนอราคา vendor) — ไม่อยู่ใน getTicket, preview, openAttachment และ timeline
- Settings `max_photos_per_quote` (ค่าเริ่มต้น 10) · หมวดไฟล์ใหม่ `quote_photo`

## 2. แจ้งเตือนกลุ่ม Lark อัตโนมัติ
| กลุ่ม | Script Property | เหตุการณ์ |
|---|---|---|
| กลุ่ม Sales (มี Sales ทุกคน) | `LARK_PRICE_GROUP_CHAT_ID` (ว่าง = `LARK_GROUP_CHAT_ID`) | 🆕 คำขอราคาใหม่ · 🛒 GM อนุมัติฝั่งขาย · 🙋 SR รับงาน · ↩️ SR ตีกลับ · ❓ SR ขอข้อมูลเพิ่ม · ⛔ ไม่อนุมัติ · ✅ ทำราคาเสร็จ · 📌 ส่งตามหลัง · 🎉 ปิดการขายได้ |
| กลุ่มผู้บริหาร (SR / SR Manager / GM) | `LARK_MGMT_GROUP_CHAT_ID` (ว่าง = ไม่ส่ง) | 🧾 ราคารอ SR Manager ตรวจ · 📦 รอ GM อนุมัติฝั่งซื้อ · 🔁 ตีกลับให้ SR แก้ราคา · ✏️ Sales ขอปรับราคา |
- เปิด/ปิดแต่ละเหตุการณ์: Settings `lark_group_events` (รายการคีย์ JSON — ลบคีย์ออก = ปิด)
- **ข้อความกลุ่มไม่มีราคา ต้นทุน GP ชื่อ Supplier หรือข้อความ comment** — มีเฉพาะ ลูกค้า · กลุ่มลูกค้า · Sales/SR · สินค้า + ปริมาณ/เดือน · ปุ่มเปิดในระบบ
- กลุ่มผู้บริหารได้ “Supplier ที่เสนอ n ราย · รูปสินค้า n รูป” เพื่อเปิดดูราคาและรูปในระบบก่อนอนุมัติ
- ราคาขายยังส่งเฉพาะ DM ของ Sales ผู้ขอ (เหมือนเดิม)
- ส่งผ่านคิว Notifications + `dispatchNotifications` (retry 5 ครั้ง) · ไม่ได้ตั้งกลุ่ม → สถานะ `no_group` (หน้าแรก Admin แสดงจำนวน)

## 3. ติดตามการขาย (New Item follow-up) — เมนู 🎯 ของ Sales
- ทุกรายการที่ GM อนุมัติราคาแล้ว = 1 แถวติดตาม: **สินค้าที่ลูกค้าสนใจ · ปริมาณที่ลูกค้าใช้ต่อเดือน · ราคาที่ลูกค้าคาดหวัง · ราคาที่เสนอ (สูง/ต่ำกว่าที่คาด %)**
- ฟอร์มขอราคา: “ราคาเป้าหมาย” เปลี่ยนชื่อเป็น **ราคาที่ลูกค้าคาดหวัง** (ยังบังคับกรอก หรือติ๊ก “ลูกค้ายังไม่บอกราคา”) · ปริมาณต่อเดือนบังคับอยู่แล้ว
- สถานะ: ยังไม่อัปเดต → **กำลังติดตาม / ส่งตัวอย่าง-ทดลอง** (มีวันติดตามครั้งถัดไป, ไม่กรอก = +7 วัน) → **ปิดการขายได้ / ไม่ได้งาน** (ต้องเลือกเหตุผล — Settings `deal_lost_reasons`; “อื่นๆ” ต้องมีหมายเหตุ)
- แท็บ: ต้องติดตาม (ถึงวันนัด หรือยังไม่อัปเดตเกิน `deal_follow_days` วันหลังได้ราคา) · ยังไม่จบ · ปิดได้ · ไม่ได้งาน · ทั้งหมด — ตัวเลขบนเมนู = ต้องติดตาม
- อัปเดตได้: Sales เจ้าของคำขอ, Sales Manager ของแผนก, Admin · ทุกครั้งลง audit log (เห็นใน timeline)
- ปิดการขายได้ → แจ้ง SR + SR Manager (DM) และกลุ่ม Sales (🎉 ไม่มีราคา)
- ไม่มีข้อมูลต้นทุนในหน้านี้สำหรับทุกบทบาท
- คอลัมน์ใหม่ใน TicketItems: `deal_status, deal_reason, deal_note, deal_next_date, deal_updated_by, deal_updated_at, deal_closed_at`

## 4. สรุป GP & การปิดการขาย — GM / SR Manager / Admin
- รายงาน → แท็บ **💹 สรุป GP & การปิดการขาย** (Sales Manager ไม่เห็น เพราะเป็นข้อมูลต้นทุน)
- ช่วงเวลา 3 / 6 / 12 เดือน / ปีนี้ / ทั้งหมด (นับตามเดือนที่ GM อนุมัติราคา) · กรองกลุ่มลูกค้า / Sales
- ตัวเลขหลัก: รายการที่เสนอ + มูลค่าขาย/เดือน · GP % ที่เสนอ · ปิดการขายได้ (อัตราปิด, Win rate) · GP % ของที่ปิดได้ + กำไรขั้นต้น/เดือน · Pipeline รอปิด
  - อัตราปิด = ปิดได้ ÷ ที่เสนอ · Win rate = ปิดได้ ÷ (ปิดได้ + ไม่ได้งาน)
  - GP % ถ่วงน้ำหนัก = Σ(กำไร/หน่วย × ปริมาณ/เดือน) ÷ Σ(ราคาขาย × ปริมาณ/เดือน)
- กราฟแนวโน้มรายเดือน (ปิดได้ / ไม่ได้ / ยังไม่จบ + อัตราปิด + GP %) · ตารางแยกเดือน · กลุ่มลูกค้า · Sales · เหตุผลที่ไม่ได้งาน · รายการทั้งหมด + **ดาวน์โหลด CSV**
