## 2. หน้าใบเสนอราคา (`?page=pricing&id=…`)
1. **หัวใบ + ขั้นตอน** (ตรวจเอกสาร → หาราคา → ส่งให้ Sales) + แจ้งเตือนถ้า Sales ขอปรับราคา / รอข้อมูล
2. **ไฟล์**: เอกสารจาก Sales และไฟล์ใบเสนอราคา vendor (SR แนบได้ ≤ 20 MB) — ผูกไฟล์กับแต่ละ vendor ได้
3. **ตรวจเอกสาร**: ติ๊ก + หมายเหตุต่อข้อ → "ยืนยันเอกสารครบ" (ต้องครบทุกข้อที่บังคับ) หรือ "ขอข้อมูลเพิ่มจาก Sales" (เลือกข้อที่ขาด)
4. **ต่อรายการสินค้า** (การ์ดพับได้): vendor แบบคอลัมน์ข้างกันสูงสุด 3 เจ้า, ปุ่ม "+ เพิ่ม Vendor" ปิดเมื่อครบ 3, ลบ vendor (ยืนยันก่อน), เลือก vendor จากทะเบียนแล้วเติมสกุลเงิน/VAT ให้อัตโนมัติ
5. **คำนวณทันที**: ต้นทุนสุทธิ/หน่วย (THB), ราคาจ่ายจริง/หน่วย, รวม × จำนวน, ป้าย "★ ถูกที่สุด", เทียบราคาเป้าหมายของ Sales (▲/▼ %)
6. **เลือกผู้ชนะ 1 เจ้า** (radio) — ถ้าไม่ใช่เจ้าถูกสุด ช่องเหตุผลขึ้นมาและบังคับกรอก
7. **แถบล่าง (sticky)**: จำนวนรายการที่พร้อมส่ง, ยอดรวมสุทธิ/จ่ายจริง, สถานะ "ยังไม่ได้บันทึก" · **บันทึกร่าง** (ไม่ต้องครบ) · **ส่งราคาให้ Sales** (ตรวจครบทุกข้อ → แสดงรายการปัญหา หรือหน้ายืนยันพร้อมตารางสรุป)
8. ออกจากหน้าโดยยังไม่บันทึก → ถามยืนยัน · ไม่ใช่ SR ผู้รับงาน / สถานะไม่ใช่ On Process → **ดูอย่างเดียว**

## 4. UAT checklist (SR)
| # | สิ่งที่ต้องลอง | ผลที่ควรได้ | ผ่าน/ไม่ผ่าน |
|---|---|---|---|
| 1 | เปิดใบที่เพิ่งรับงาน → กด "ยืนยันเอกสารครบ" โดยยังติ๊กไม่ครบ | ระบบบอกว่าข้อไหนยังขาด | |
| 2 | ติ๊กครบแล้วยืนยัน | ขั้นตอนเปลี่ยนเป็น "หาราคา / เทียบราคา" | |
| 3 | ใส่ราคา 3 เจ้า (มี USD 1 เจ้า + ใส่อัตราแลกเปลี่ยน) | เห็นต้นทุนสุทธิเป็นบาททันที และมีป้าย "ถูกที่สุด" ถูกเจ้า | |
| 4 | กด "+ เพิ่ม Vendor" อีก | ปุ่มกดไม่ได้ (ครบ 3) | |
| 5 | เลือกเจ้าที่ไม่ถูกที่สุด | มีช่องเหตุผลขึ้นมา ส่งไม่ได้ถ้าไม่กรอก | |
| 6 | บันทึกร่างแล้วปิดแท็บ เปิดใหม่ | ราคาที่กรอกยังอยู่ครบ | |
| 7 | ส่งราคาให้ Sales | Sales ได้ Lark + เห็นตารางเทียบราคาพร้อม Origin/Incoterm | |
